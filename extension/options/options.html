ActivaHandleNombre / notaListas

Una cuenta con etiquetas se filtra si al menos una de sus listas está activa. Las cuentas sin etiquetas siempre se filtran. Apagar una lista no borra nada.

Reglas adicionales además de la lista de cuentas. Ejemplos: handle *promo* (comodín), nombre visible o biografía que contenga vendo seguidores, texto que coincida con una expresión regular, idioma ja. Nombre y biografía se leen de la API de X y se aplican al autor (y a la cuenta citada si activas las citas). Las reglas de texto son las más propensas a falsos positivos.
